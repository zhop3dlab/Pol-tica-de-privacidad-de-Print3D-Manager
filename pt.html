Política de privacidade do Print3D Manager

Última atualização: 31 de agosto de 2026

Esta política explica que dados o Print3D Manager ("a app") trata, para que finalidade, com que base legal, durante quanto tempo são conservados, e que opções tens. Está escrita para descrever exatamente o que a app faz hoje, não funcionalidades futuras.

1. Quem trata os dados

O Print3D Manager é uma app desenvolvida de forma independente para a gestão de uma oficina de impressão 3D (custos, impressoras, materiais, projetos, clientes, orçamentos e faturas).

Contacto: zhop3dlab@gmail.com.

2. Princípio geral: a app é local

Toda a informação que introduzes (impressoras, materiais, projetos, clientes, orçamentos, faturas, inventário) fica guardada apenas no teu próprio dispositivo. Não precisas de criar nenhuma conta nem de ligação à internet para usar a app.

Nenhum dado do teu negócio é enviado para os nossos servidores ou para terceiros.

3. Se usas a app para gerir dados dos teus próprios clientes

Se guardas na app dados dos teus clientes (nome, morada, identificação fiscal, email...) para orçamentos e faturas, és tu o responsável pelo tratamento desses dados perante os teus próprios clientes — tal como se os gerisses numa folha de cálculo ou num programa de faturação. O Print3D Manager é apenas a ferramenta que usas para os guardar, sempre no teu próprio dispositivo.

Isto significa que és tu quem deve garantir que tem uma base legal adequada para tratar os dados dos teus clientes (normalmente, a relação comercial/contratual com eles) e responder aos pedidos de acesso, retificação ou eliminação que eles te façam diretamente.

4. Dados que nunca saem do teu dispositivo

  • Ficheiros G-code: se usas o analisador de G-code, o ficheiro é lido e analisado inteiramente no teu dispositivo. O conteúdo nunca é enviado para a internet nem partilhado com ninguém.
  • Cópias de segurança locais: exportar/importar os teus dados num ficheiro JSON é uma operação completamente local.
  • PDFs de orçamentos e faturas: são gerados no teu dispositivo. Partilhá-los ou descarregá-los é sempre uma ação explícita tua.
  • Lembretes de entrega: o aviso da data de entrega de um projeto é uma notificação agendada inteiramente pelo sistema operativo do teu dispositivo; nunca passa por nenhum servidor nosso.

5. O que NÃO fazemos

  • Não vendemos os teus dados a ninguém.
  • Não acedemos ao conteúdo dos teus projetos, clientes ou faturas — nem sequer os revemos manualmente.
  • Não usamos os teus dados de negócio para treinar modelos de inteligência artificial.
  • Não pedimos permissões de câmara, contactos, localização nem microfone — a app não precisa delas e não as solicita.
  • Não enviamos nem armazenamos nenhum dado do teu negócio em nenhum servidor.
  • Não mostramos anúncios nem usamos nenhum identificador publicitário — a app é gratuita e não tem nenhuma funcionalidade paga ativa neste momento.

6. Os teus direitos

Tens direito a aceder, retificar, eliminar, limitar o tratamento, opor-te e pedir a portabilidade dos teus dados. Como todos os teus dados vivem apenas no teu dispositivo, podes exercer estes direitos tu mesmo a qualquer momento:

  • Descarregar uma cópia dos teus dados num ficheiro JSON (Mais → Dados).
  • Desinstalar a app a qualquer momento, o que remove todos os dados guardados no teu dispositivo.

Se precisares de ajuda com algum destes direitos, ou tiveres dúvidas sobre esta política, contacta zhop3dlab@gmail.com.

Se considerares que não tratámos bem o teu pedido, tens o direito de apresentar uma reclamação junto da autoridade de controlo de proteção de dados do teu país (em Portugal, a CNPD, https://www.cnpd.pt).

7. Menores de idade

A app não se destina a menores de idade e não recolhemos conscientemente dados de menores.

8. Alterações a esta política

Se esta política mudar de forma relevante, a data no topo do documento será atualizada. O uso continuado da app após uma alteração implica a aceitação da política atualizada.
